# Random Quote Machine

A freeCodeCamp Front End Development Libraries certification project.

Built with plain HTML, CSS and JavaScript. Shows a random quote and author,
with a "New Quote" button and a "Tweet Quote" link that opens
twitter.com/intent/tweet with the current quote.

Live demo: see the Netlify URL submitted on freeCodeCamp.

The freeCodeCamp test suite script
(`https://cdn.freecodecamp.org/testable-projects-fcc/v1/bundle.js`) is
included in `index.html` so the project's tests can be run in the browser.
